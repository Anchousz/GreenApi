# Telegram Web Client на GREEN-API

Веб-клиент для Telegram через [GREEN-API](https://green-api.com/). Работает в браузере: отправка и получение текстовых сообщений в реальном времени, список чатов, поиск, история, статусы доставки.

> ⚠️ Проект рассчитан на **Telegram-юзербот** (обычный второй аккаунт). Это связано с тем, что создание бота через `@BotFather` в некоторых регионах заблокировано. Если у вас есть возможность создать бота — можно использовать и его, просто сменив инстанс в GREEN-API.

## Возможности

- Авторизация через `idInstance` + `apiTokenInstance`
- Отправка и получение сообщений в реальном времени (long polling)
- Список чатов с превью последнего сообщения и счётчиком непрочитанных
- Поиск по чатам
- Создание чата по номеру телефона, `@username` или числовому `chatId`
- Загрузка истории (до 100 последних сообщений)
- Статусы: отправлено / доставлено / прочитано / ошибка
- Повторная отправка упавших сообщений
- Адаптив под мобильные и десктоп
- Локальный прокси для обхода CORS

## Стек
